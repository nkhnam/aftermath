# AfterMath — Qoder Build Log

## Initial Quest Mode Planning

**Date:** 2026-08-02
**Goal:** Build a polished, demo-ready MVP of AfterMath — an AI Financial
Pre-Mortem web app — using deterministic TypeScript logic.

## Spec Decisions

1. **Framework:** Next.js 16 with App Router, TypeScript, Tailwind CSS 4
2. **Animations:** Framer Motion for sequential agent reveal and score transitions
3. **Icons:** Lucide React
4. **No backend:** All logic runs client-side. No database, no auth, no API.
5. **Financial engine:** Pure functions — `calculateMonthlyPayment`,
   `remainingBalance`, `runMonthlySimulation`
6. **Scoring:** 7 transparent risk factors, sum clamped 0–100
7. **Risk score targets:** Risky = ~81, Safer = ~34
8. **Critical turning point:** Month 19 (first month after income disruption
   ends, when emergency fund is below 3 months of essential costs)

## Bugs Found and Fixed

   `(prevMonth?.monthlyPayment ?? 0 / 1_000_000)` evaluated `0 / 1_000_000`
   instead of `(prevMonth?.monthlyPayment ?? 0) / 1_000_000`. Fixed with
   intermediate variables.
2. **`Replay` icon not exported from lucide-react** — replaced with
   `RotateCcw`.
3. **Unused import `formatVNDfull`** in scenario-form.tsx — removed.
4. **Extra `)` in className** in decision-setup.tsx — removed.
